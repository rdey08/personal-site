I work on applied machine learning for scientific problems: models that fuse
messy, multi-modal real-world data into predictions scientists can use. At the
NMSU KDD Lab, my senior-thesis research uses multi-branch LSTMs to predict
rangeland herbaceous biomass and how it changes, fusing satellite,
precipitation, cattle-GPS, and land-cover signals. At NASA's Planetary Data
System (Atmospheres Node), I develop ELSA, the web application planetary
scientists use to generate PDS4 metadata for large datasets and prepare it for
archiving.
